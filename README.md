## 🚀 Running & Building

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the live website.

### 3. Build for Production
```bash
npm run build
```
Production assets are generated in the `dist/` directory, optimized for deployment to Vercel, Netlify, Cloudflare Pages, or AWS.
